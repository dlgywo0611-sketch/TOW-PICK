# 프론트엔드 자동 테스트

## 실행

Node.js 20 이상에서 별도 패키지 설치 없이 실행한다.

```bash
npm test
npm run test:syntax
```

백엔드 회귀 테스트는 `SECRET_KEY`를 설정한 뒤 `python -m pytest -q`로 실행한다.

## 검사 범위

| 사용자 흐름 | 자동 검사 |
|---|---|
| 회원가입·로그인·커플 연결 | 필수 UI와 실제 API 경로 계약, Python API 회귀 테스트 |
| 공동결정 생성·조건 제출 | 입력 파싱·검증, 비공개 조건 상태, 실제 API 경로 계약 |
| 추천 성공·실패·수동 후보 | 추천 가능 조건, 실패 안내, 수동 후보 전환 |
| 후보 변경·승인·확정 | 최신 후보 승인 규칙, 사용자별 승인, Python 상태 전이 테스트 |
| USB·BLE | 재연결, 해제, 오류 정리, 공동결정 승인과 분리 여부 |
| PC·모바일 | viewport, 핵심 반응형 구간, 6개 서비스 화면 존재 여부 |
| 오류 처리 | 네트워크, 시간 초과, 검증 오류, 중복 요청 분류 |

GitHub Actions는 모든 pull request에서 Node 회귀 테스트, 전체 프론트 스크립트 문법 검사, Python API 테스트를 실행한다. 실제 Web Serial/Web Bluetooth 권한 창과 물리 장치는 자동화하지 않고 수동 브라우저 검사 대상으로 남긴다.
