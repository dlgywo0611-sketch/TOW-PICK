# 백엔드 2차 프론트엔드 통합 검증

검증일: 2026-11-25  
기준 브랜치: `test/backend-phase2-frontend-integration`

## 실제 API 연동 범위

- 커플 초대 코드 24시간 정책, 재발급, 만료·비활성 안내
- 확정 공동결정 목록·상세와 레거시 결정 조회 보완
- 본인 만족도 1~5점 조회·작성·수정
- 기념일·일정 CRUD, 종일·시간 지정, 반복 캘린더
- 본인 알림 동의·철회, D-1·당일·시각 설정
- 대시보드의 진행 결정·최근 확정·일정·커플·알림 설정
- 추천 1회, 실패 후 수동 후보 또는 새 결정 안내, 독립 승인

## 자동 테스트

| 검증 | 결과 |
|---|---|
| `npm test` | PASS — 프론트 회귀 15개 묶음, 결정 UI 로직 12/12, USB/BLE 재연결 |
| `npm run test:syntax` | PASS — 프론트 스크립트 25개 |
| `.venv/Scripts/python -m pytest -q` | PASS — 59 tests, 14 subtests |

백엔드 테스트는 32자 이상의 테스트용 `SECRET_KEY`를 환경 변수로 주입해 실행했다.

## Mock 및 미구현 경계

- 알림 센터 목록과 읽음 상태는 Mock/이 기기 저장이다.
- OUR PET 레벨·경험치·성장 상태는 Mock이다.
- 표시 이름 변경은 이 기기 저장이다.
- n8n/Gmail 실제 발송은 미구현이며 화면에서 발송 완료로 표시하지 않는다.
- PET DOCK 물리 장치 연결은 실제 장치가 있는 PC에서 추가 검증해야 한다.
